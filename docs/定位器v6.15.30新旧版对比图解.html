1一图看懂：新建用例的流程变了什么

同样的动作——「选中元素 → 添加测试用例」，两种版本走过的路完全不同：

🔲 原版：按用例归档（1 用例 = 1 套三件套）

元素文件强制随用例新建，无条件锁死
1
选中元素，目标用例选「➕ 新建」
输入用例名，如 search_play
2
元素文件被强制切到「➕ 新建」
❌ 不允许选已有文件——「写入元素文件」与目标用例必须同态，混搭直接拦下
3
保存 → 生成 1:1:1 三件套
test_search_play.py ＋ SearchPlayPage.py ＋ SearchPlayElements.py（全新文件）
4
写第二条用例？再抄一遍元素
搜索按钮、歌曲列表…在新的文件里再存一份

🟦 现版：按页面共享（元素1 · 用例多 · 页面操作多）

新增「页面选择」，元素文件跟随页面，查重自动处理
1
选中元素，目标用例选「➕ 新建」
输入用例名，如 search_collect
2
新增：选择页面
「➕ 新建页面文件…」或复用已有页面（如 SearchPage.py）——元素文件自动对齐页面绑定的文件
3
保存 → 服务端组装 + 自动查重
同定位元素已存在 → 复用库内原名，不写重复行；同名不同定位 → 硬拦（禁止静默覆盖）
4
元素定义只存在一份
所有用例共享同一个元素文件，改版只改一处

2直观演示：写完第 2 条用例之后，元素库长什么样

场景：用例 A「搜索歌曲并播放」、用例 B「搜索歌曲并收藏」。两条用例都要点同一个「搜索按钮」。

原版 · 用例包入库后
elements/
├── SearchPlayElements.py含搜索按钮 ①
├── SearchCollectElements.py含搜索按钮 ②
└── …第 3 条用例 → 搜索按钮 ③④⑤…
⚠ 同一个按钮存了 N 份：改版要改 N 处，
漏一处该用例悄悄跑挂

每条用例自带一套元素 → 重复是必然产物，去重永远追不上新增

现版 · 用例包入库后
elements/
├── SearchPageElements.py搜索按钮 · 唯一一份
├── PlayerPageElements.py
└── CollectPageElements.py
✓ 用例 A import SearchPage + Player
✓ 用例 B import SearchPage + Collect
✓ 用例 C 复用 SearchPage → 0 份新增

元素跟页面走，用例只做引用 → 重复根本不会产生，无需去重

3界面上能看到的变化（逐项对照）

变化点原版（≤ 6.15.29）现版（6.15.30）
新增页面选择无。新用例的页面文件永远按用例名派生（xxxPage.py 随包新建），只读展示弹窗出现「写入页面文件」下拉：➕ 新建页面（默认）／复用已有页面。选已有页面 → 页面方法追加进该文件，新用例 import 它
改变元素文件锁定选「新建用例」→「写入元素文件」被强制切到「➕ 新建」，其他选项点不动解除锁定：可保持新建，也可改选已有元素文件（共享）；选中已复用页面时自动对齐其绑定文件
新增保存时查重不查重——同名直接覆盖、同定位直接新增（元素文件私有所以无所谓）服务端组装时自动查重：同定位 → 回填库内原名（弹窗里元素名自动改，后续步骤继续引用）；同名异定位 → 保存被拦并说明原因
改变落点预览条「将生成并锁死：test_x.py · xPage.py · xElements.py」按所选模式实时显示：新页面 → 三个文件名；已有页面 → 「页面方法追加到 XxxPage.py（元素 → xxxElements.py，同定位自动复用原名）」
改变一键添加默认文件默认写 locator_gui_elements.py——没有页面 import 它，元素静默失效默认指向被页面引用的「活文件」（如 aaaaElements.py）；写向无人引用的文件时弹确认，明确告知「会静默失效」
删除同态强制规则「写入元素文件」与「目标用例」必须同时新建或同时选已有，否则拒绝保存规则取消。合法性由服务端统一校验：唯一保留的硬约束是「已有页面的元素必须写进它绑定的文件」（保存前自动对齐）

4现版的三条查重规则（保存时自动执行）

你输入的元素名只是「提议」，库内已有同定位元素时以库为准：

♻️

同定位 → 复用原名

目标元素文件里已有相同「定位方式＋定位值」→ 直接用库内元素名，不写重复行。弹窗里你的名字会被替换成库名，后续步骤自动衔接。

输入 home_btn_x
→ 复用库内 btn_home ✓
📋

别处有同定位 → 复用名＋复制行

其他元素文件里已有同定位 → 复用它的名字，定义行原样复制进目标文件（保留等待秒数/中文名），页面绑定不受影响。

SearchElements: search_btn
→ 本文件也生成 search_btn
  (定义一致，名字统一)
⛔

同名异定位 → 硬拦

目标文件里已有同名元素但定位不同 → 拒绝保存。共享元素文件里静默覆盖会牵连其他用例，必须换名。

⛔ 已有「btn_home」但定位不同
——请换一个元素名
