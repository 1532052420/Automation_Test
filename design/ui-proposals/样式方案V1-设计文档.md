# 「保存到哪一步」分段控件（V1）设计文档

> 组件：添加测试用例弹窗 · 顶部用途选择区（红框区域）
> 选定方案：样式方案 V1 · 分段控件（Segmented Control）
> 范围：**仅替换该区域**，弹窗其余部分（三栏、按钮、底部提示条）维持现状
> 状态：待评审 → 评审通过后按「落地实现映射」开发

---

## 1. 设计意图

- 三个用途选项（① 仅元素 / ② 元素+用例+操作 / ③ 登记随机弹窗）是**互斥单选**，
  用分段控件表达「一整条里的三段」语义，替代现在松散的 radio 横排。
- 选中段**白底浮起**在灰滑槽上，视觉焦点明确；未选中段退后为次级文字。
- 序号①②③保留（呼应「三栏流程」）；②保留「推荐」橙色徽章（在蓝色系中形成唯一焦点）。
- 交互逻辑零改动：仍为单选组（radio 语义），选中即触发既有 `onPurposeChange()` 流程。

---

## 2. 布局与结构

```
┌──────────────────────────────────────────────────────────────────────┐
│ 保存到哪一步 (?)                                    ← 行标题，13px     │
│ ┌────────────┬──────────────────────────┬──────────────┐              │
│ │ ① 仅元素   │ ② 元素+用例+操作 [推荐]   │ ③ 登记随机弹窗 │  ← 滑槽      │
│ └────────────┴──────────────────────────┴──────────────┘              │
│      未选中（灰字）        选中（白底浮起·蓝字）          未选中        │
└──────────────────────────────────────────────────────────────────────┘
```

- 行容器：标题行 + 分段组，纵向间距 12px
- 分段组：`display:flex`，三段**等宽**（`flex:1`），文字居中
- 「?」帮助问号：14px 灰底白字圆标（沿用现有 `.q` 图标语义，title=帮助说明）

## 3. 设计规格（Design Tokens）

### 3.1 颜色

| Token | 日间值 | 用途 |
|---|---|---|
| `--seg-track` | `#f2f3f5` | 滑槽底色 |
| `--seg-active-bg` | `#ffffff` | 选中段底色 |
| `--seg-active-text` | `#409eff` | 选中段文字/序号 |
| `--seg-active-ring` | `0 0 0 1px rgba(64,158,255,.18)` | 选中段 1px 描边（随阴影） |
| `--seg-idle-text` | `#606266` | 未选中段文字/序号 |
| `--seg-hover-bg` | `#e9ebee` | 未选中段悬停底色 |
| `--seg-badge-bg` | `#ff9800` | 「推荐」徽章底 |
| `--seg-badge-text` | `#ffffff` | 徽章文字 |
| `--seg-title` | `#606266` | 行标题文字 |

### 3.2 尺寸与圆角

| 项 | 值 |
|---|---|
| 滑槽内边距 | `4px`（上/下/左/右） |
| 滑槽圆角 | `10px` |
| 段圆角 | `8px` |
| 段内边距 | `11px 8px` |
| 段字号 | `13.5px`，选中 `font-weight:600` |
| 序号徽章 | `18×18px` 圆形，`1.5px solid currentColor`，字号 `11px`，右距 `7px` |
| 推荐徽章 | 字号 `10px`，`padding:3px 6px`，圆角 `999px`，左距 `6px` |
| 行标题 | `13px / 600`，下距 `12px` |
| 段阴影（选中） | `0 1px 4px rgba(0,0,0,.14)` + 3.1 的 ring |

### 3.3 状态表

| 状态 | 底色 | 文字 | 附加 |
|---|---|---|---|
| 未选中 | 透明（滑槽底透出） | `#606266` | 悬停 → `--seg-hover-bg` |
| 选中 | `#ffffff` | `#409eff` 加粗 | 阴影 + 1px 蓝描边 |
| 焦点（键盘） | 同选中/未选中 | — | `outline:2px solid #409eff; outline-offset:2px` |
| 禁用（预留） | 透明 | `#c0c4cc` | `cursor:not-allowed`（当前无禁用场景） |

## 4. 交互规格

| 行为 | 规格 |
|---|---|
| 点击切换 | 点任意段 → 该段变为选中态，其余回未选中；**立即触发既有 `onPurposeChange()`**（栏位显隐/联动逻辑不变） |
| 键盘 | 保留 radio 原生行为：`←`/`→` 在三段间切换，`Space` 选中；焦点环见状态表 |
| 悬停 | 未选中段底色加深至 `#e9ebee`（150ms 过渡）；选中段悬停无变化 |
| 切换动效 | 底色/文字 150ms ease 过渡；不做滑块位移动画（三段等宽下白底跳变即可，避免多余实现） |
| 长文案兜底 | 段内 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`（极端窄窗不换行） |
| 逻辑不变项 | `purposeValue()`、`onPurposeChange()`、三栏显隐、`state.tempCase` 流程**全部不动**——本组件为纯视觉替换 |

---

## 5. 无障碍（WCAG AA）

- 对比度：选中段 `#409eff` on `#ffffff` ≈ 3.1:1（14px 加粗 = 大文本，达标）；未选中 `#606266` on `#f2f3f5` ≈ 5.9:1 达标
- 结构：容器 `role="radiogroup" aria-label="保存到哪一步"`；每段内保留原生 `input[type=radio]`（视觉隐藏）——**不丢弃原生 radio**，保证读屏与键盘
- 「推荐」徽章加 `aria-label="推荐"`（装饰性文字对读屏降权）

## 6. 夜间模式适配（项目硬边界：不覆盖主题契约）

沿用「日间默认 + `html.night` 覆盖」机制，本组件仅在夜间覆盖以下 token：

| Token | 夜间值 |
|---|---|
| `--seg-track` | `#2b2f36` |
| `--seg-active-bg` | `#1e2b3a` |
| `--seg-active-text` | `#66b1ff` |
| `--seg-idle-text` | `#9ca3af` |
| `--seg-hover-bg` | `#333945` |
| `--seg-title` | `#9ca3af` |
| 徽章 | 不变（橙底白字在深浅底均可读） |

## 7. 落地实现映射（改动点清单）

### 7.1 HTML（`element_locator/static/index.html`）
替换红框区域为：

```html
<div class="seg-row">
  <span class="seg-title">保存到哪一步<span class="q" title="选择本次保存的范围">?</span></span>
  <div class="seg-group" role="radiogroup" aria-label="保存到哪一步">
    <label class="seg"><input type="radio" name="el-purpose" value="only"><span class="num">1</span>仅元素</label>
    <label class="seg"><input type="radio" name="el-purpose" value="all" checked><span class="num">2</span>元素 + 用例 + 操作<span class="badge">推荐</span></label>
    <label class="seg"><input type="radio" name="el-purpose" value="popup"><span class="num">3</span>登记随机弹窗</label>
  </div>
</div>
```
（radio 用 `position:absolute; opacity:0` 视觉隐藏，保留键盘/读屏；选中样式用
`input:checked + …` 或 JS 同步 `.seg.on` 类。）

### 7.2 CSS（`element_locator/static/index.html` 内联样式区 / style.css）
- 新增 3.1 全部 token + 段样式 + 状态表 + `html.night` 覆盖（§6）
- 其余弹窗样式**零改动**

### 7.3 JS（`element_locator/static/index.js`）
- 既有 `onPurposeChange` 的 `change` 监听**不动**
- 仅新增：change 时同步 `.seg.on` 类（约 3 行）
- `purposeValue()` / `state.tempCase` / 三栏显隐逻辑**不动**
