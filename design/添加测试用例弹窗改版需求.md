# 「添加测试用例」弹窗改版需求文档

> 依据：`design/proto-case-tri.png`（三栏式原型，2026-09-23 选定）
> 原型源文件：`design/proto-case-tri.html`
> 基线版本：v6.96 · 状态：待实施

---

## 1. 改版目标与边界

**只改样式与布局，不改任何功能。**

- ✅ 改：弹窗布局、视觉样式、同屏组织方式（分段控件、卡片、图标化选择、插入点可视化、状态条）
- ❌ 不改：字段集合（一个不多一个不少）、字段顺序语义、校验规则、保存/撤销逻辑、接口与数据结构、三件套流程、弹窗规则库交互

**验收总原则（强制）**：按下方映射表逐字段一比一核对，旧弹窗每一个控件在新弹窗中必须存在且行为等价；缺一项即验收不通过。

---

## 2. 新旧布局对照

| 维度 | 旧弹窗（现状） | 新弹窗（改版后） |
|---|---|---|
| 用途选择 | 表单区顶部 radio 行（①仅元素 / ②元素+用例+操作 / ③登记随机弹窗） | 头部分段控件（segmented），选中项白底蓝字浮起，②带「推荐」角标 |
| 三栏结构 | `.flow-cols` 三栏（有边框浅底、栏头文字） | 三张白卡（`.card`）：圆角 12 + 灰描边 + 栏头「编号圆片 + 标题 + 右侧灰字说明」 |
| 操作类型 | 普通下拉 `el-op-type` | **常用 6 类图标卡片**（2×3 网格：点击/输入/长按/断言文本/断言Toast/等待出现）+ 其余类型收纳（见 §4.3） |
| 用例步骤列表 | `el-steps-list` 纯文本列表 | 步骤列表卡片化：插入点渲染为**蓝色虚线高亮行**「＋ 新步骤将插入到这里（第 N 步）」，其下预览新步骤行 |
| 绑定说明 | `el-link-note` 纯文本 | 蓝色信息条（🔗 图标 + 页面/元素文件代码名） |
| 底部反馈 | `el-result` 文本 | **绿色三件套状态条**（✅ 元素＋用例行＋页面方法三个落点明示）；`el-result` 保留用于保存结果 |
| 页宽 | 自适应 | `min(1000px, 94vw)`，三栏 300/300/剩余 |

## 4. 明确的不变项（改版红线）

1. 字段集合与字段语义：映射表之外**不得新增/删除/重命名**任何业务字段。
2. 所有校验规则（元素名合法性、必填项、数值范围）与保存流程（三件套/仅元素/弹窗规则）不变。
3. 全部接口与数据结构不变（纯前端样式与 DOM 组织改动）。
4. 问号帮助气泡全部保留，文案不变。
5. 用途 ③ 弹窗规则库的交互与字段全套保留。
6. 夜间模式（`html.night`）适配：新样式全部走 `style.css` 既有 CSS 变量，不得硬编码颜色。

## 5. 样式规格（新增样式件）

| 样式件 | 规格 |
|---|---|
| 分段控件 | 背景 `--panel2` 圆角 10，内 padding 3px，选中项白底 + 蓝字 + 微阴影；「推荐」角标 #b26a00/#fff7e6 |
| 三栏卡片 | 白底、1px `--line` 描边、圆角 12；栏头编号圆片 20px 蓝底白字 |
| 已选元素信息卡 | 蓝调底（`#f5f8ff`/夜 `--brand-tint`）、缩略图占位（元素高亮框示意）、定位值 mono 蓝字 |
| 操作类型图标卡 | 2×3 网格，默认 1.5px 灰描边；选中蓝描边 + 蓝底衬 + 外圈 3px 淡蓝光晕；图标 30px 圆片 |
| 插入点行 | 上下 1.5px 蓝虚线 + `#eaf3fd` 底 + 蓝字「＋ 新步骤将插入到这里（第 N 步）」；新步骤预览行白底蓝描边 + 投影 |
| 三件套状态条 | `#eaf7ee` 底 + `#cdebd6` 描边 + `#248a3d` 强调字，✅ 前缀 |
| 字段行高 | 统一 34px（原 38px），栏内 gap 8px，保证三栏等高不拥挤 |
